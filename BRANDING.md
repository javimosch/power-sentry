# PowerSentry

**Infrastructure Power Monitoring & Cost Optimization**

## Project Identity

**Name**: PowerSentry  
**Tagline**: Monitor. Optimize. Save.  
**Purpose**: Real-time power consumption monitoring and cost projection for infrastructure servers.

## Brand Colors

- **Primary**: #0ea5e9 (Sky Blue) - Trust, technology, clarity
- **Secondary**: #10b981 (Emerald) - Energy efficiency, cost savings
- **Accent**: #f59e0b (Amber) - Warning, peak pricing alerts
- **Dark**: #0f172a (Slate) - Professional, infrastructure

## Logo Concept

A shield icon with a lightning bolt, representing protection (sentry) and energy/power monitoring.

## Target Users

- DevOps engineers managing server infrastructure
- System administrators monitoring power costs
- Homelab enthusiasts tracking energy consumption
- Businesses optimizing operational expenses

## Key Features

- Real-time power monitoring
- Cost projection and simulation
- Multi-server centralized dashboard
- French electricity pricing (peak/off-peak)
- WebSocket-based architecture
- Historical data analysis
- Alert system for cost anomalies
